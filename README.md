# CyberSense — Cybersecurity Quiz

A responsive cybersecurity quiz with 15 multiple-choice questions, immediate answer explanations, final scoring, and an answer review.

## Run locally

Open `index.html` in your browser. No dependencies or build step are required.

## Deploy to Vercel

Import this repository into Vercel. Select **Other** as the framework preset, leave the build command empty, and use the repository root as the output directory. The repository includes `vercel.json`.

## Features

- 15 questions covering phishing, authentication, malware, privacy, networks, and incident response
- Immediate feedback and explanations
- Final score and complete answer review
- Retry option
- Responsive layout and keyboard-friendly controls

Quiz answers remain in browser memory; there is no backend or account requirement.
